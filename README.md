# 🛒 E-Commerce Sales & Customer Analytics

## 📌 Project Overview

An end-to-end **E-Commerce Sales & Customer Analytics** project using **Python, SQL, and Power BI** to analyze sales, customer behavior, product performance, profitability.

## 🛠️ Tools Used

* **Python:** Pandas, NumPy
* **SQL:** Data analysis and business queries
* **Power BI:** Data modeling, DAX, KPIs and dashboard

## 🔄 Project Workflow

```text
Raw Data
   ↓
Python EDA & Data Cleaning
   ↓
SQL Analysis
   ↓
Power BI Dashboard
   ↓
Business Insights
```

## 📊 Key KPIs

* Total Revenue
* Profit Margin %
* average rating
* Total Profit
* Total orders
* Total customers
